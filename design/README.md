# design

Fuente única del estilo visual de KEPLER.

| Ruta | Contenido |
|---|---|
| `assets/` | Logo e isotipo |
| `figma-exports/` | Exportaciones de pantallas (AR, Archives, dashboard) |
| `userflow.pen` | Flujo de usuario (pen.dev) |
| `reference/legacy-screens/` | Capturas de la v0.7 para comparar paridad visual |
| `tokens.json` | *(pendiente)* tokens de color, blur, bordes, tipografía y espaciado, extraídos de `legacy/apps/web/src/css/system/tokens.css`. Genera el tema de SwiftUI y del escritorio |
