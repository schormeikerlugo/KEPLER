# design

Fuente única del estilo visual de KEPLER.

| Ruta | Contenido |
|---|---|
| `assets/` | Logo e isotipo |
| `figma-exports/` | Exportaciones de pantallas (AR, Archives, dashboard) |
| `userflow.pen` | Flujo de usuario (pen.dev) |
| `reference/legacy-screens/` | Capturas de la v0.7 para comparar paridad visual |
| `tokens.json` | Tokens de color, tipografía, radios, espaciado, sombras y movimiento, extraídos del CSS de la v0.7. Fuente única para escritorio e iPhone |
| `fonts/` | Jura (SIL OFL, ver `OFL.txt`): variable y 4 instancias estáticas (400-700) para motores sin soporte de fuentes variables |
| `mapa/` | Estilo Odradek (`odradek.json`, de la v0.7) con `{PMTILES}`/`{GLYPHS}` que rellena la app, y glifos Noto Sans Regular (SIL OFL) para que el mapa funcione sin internet |
| `reference/prototipos/` | Capturas de los prototipos de escritorio (Slint, Iced) junto al dashboard de la PWA |
